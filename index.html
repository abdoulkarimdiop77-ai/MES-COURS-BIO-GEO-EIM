⚙️ Activer l'import de fichiers

À faire une seule fois : ouvre Supabase → SQL Editor → New query → colle ce code → clique Run.

insert into storage.buckets (id, name, public)
values ('ressources', 'ressources', false)
on conflict (id) do nothing;

drop policy if exists "ressources_owner_all" on storage.objects;
create policy "ressources_owner_all" on storage.objects
for all to authenticated
using (bucket_id = 'ressources' and (storage.foldername(name))[1] = auth.uid()::text)
with check (bucket_id = 'ressources' and (storage.foldername(name))[1] = auth.uid()::text);

Formats acceptés : PDF, Word, Excel, PowerPoint, images. Taille max : 50 Mo par fichier.
