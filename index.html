Étape 2 : Récupérer vos clés API Supabase

Dans Supabase, rendez-vous dans Project Settings > API et copiez :

  • Project URL (ex: https://xyz.supabase.co)
  • Project API key (anon / public) (clé commençant par eyJ...)
Étape 3 : Déploiement automatique sur Vercel

Sur vercel.com, importez votre dépôt GitHub abdoulkarimdiop77-ai/MES-COURS-BIO-GEO-EIM. Dans les Environment Variables du projet Vercel, ajoutez :

VariableValeur
SUPABASE_URLVotre URL de projet Supabase
SUPABASE_ANON_KEYVotre clé Anon publique

💡 La fonction Serverless Vercel incluse (/api/config) injectera automatiquement ces clés en production sans aucune configuration manuelle !
